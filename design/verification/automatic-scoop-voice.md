# Automatic Scoop voice and compact controls — 2026-10-07

- Removed the voice settings/preview row and the per-reply Read aloud controls. New successful recipe-chat replies speak automatically with the existing Kokoro Heart streaming adapter. The initial greeting and reopened conversation history are not synthesized.
- A speaker icon in the chat header toggles mute. Its accessible name changes between Mute Scoop and Unmute Scoop; aria-pressed reflects whether mute is active. The choice persists as `pantry.scoop.muted` in browser localStorage, with a session choice retained if storage is blocked. Unmuting affects subsequent replies and does not replay old messages.
- Muting cancels active playback and its request, closes any prepared idle audio context, and prevents `voice.speak` from running on new replies. It also suppresses preparation of audio while muted. A reply arriving after mute, chat disposal or page hiding does not trigger TTS. Unmuting itself makes no generation request.
- The microphone is an icon button with a 44 px target, directly above Send in the composer's action column. Recording is indicated by a pressed state, coloured outline and a live status message. Final-only automatic dictation submission is preserved.
- Send and microphone taps prepare/resume Web Audio before the asynchronous answer arrives, without contacting TTS. Playback consumes that prepared context; this preserves gesture-based audio activation for automatic replies. Closing/hiding the chat releases idle prepared audio as well as cancelling playback.
- `npm run check`: TypeScript and 328 tests pass. New tests cover remembered mute with no speech calls, mute during pending/active replies, unmute without replay, cancellation and late callbacks, unavailable storage, user-gesture audio preparation and cancellation before audio resume completes.
